# Просмотр результата tandem

Этот сценарий знакомит с текущим продуктом и его основаниями.
Установка и команды для обеих платформ приведены в [README](../README.md).

1. Выполните `tools/run_demo.py` интерпретатором из созданной `.venv`.
   При `Status: complete` откройте новый HTML по напечатанному пути.
   Новый запуск дважды выполняет агента на официальном mock с seed 42.
2. На вкладке плана проверьте ресурсы: 3 кампании, 20 пилотов,
   5 976 контактов и 30 632 у.е. вместе с пилотами. Уникальных клиентов
   в финальных кампаниях — 2 476; контакты пилотов могут повторяться.
3. Выберите `tandem_03`: переход `tariff_8 → tariff_10` в MID связан
   с пилотами №5 и №19. Из карточки перейдите в отфильтрованный журнал.
4. В таблице альтернатив сравните Push, SMS, рекламу и звонок.
   Аудитория и остальные кампании фиксированы. Оценки +1 013 для Push
   и −5 563 для SMS — модельный дополнительный эффект финальной кампании
   после затрат; они не являются измеренной прибылью всего запуска.
5. На вкладке проверяемости найдите preflight, версии и хеши.
   Скачайте CSV/JSON: это исходные артефакты данного запуска.
6. Для измеренного результата откройте [карту доказательств](evidence.md).
   В ней указаны исходные версии, положительные и отрицательные сценарии,
   смешанные результаты сравнения адаптивности и команды воспроизведения.

Готовый [сохранённый HTML](../reports/decision_report.html) можно открыть без
повторного расчёта. Это отдельный режим просмотра: он показывает ранее
полученный результат. Сервер, сеть и API-ключи для просмотра не требуются.

[Устройство отчёта](decision_report.md) описывает значения чисел и проверки
целостности. [Алгоритм](approach.md) объясняет причины выбора и ограничения.

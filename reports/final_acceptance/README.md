## Объём и ограничения независимости

- Выполнен новый сетевой `git clone --branch main --single-branch`.
  HEAD и origin/main при заключительной сверке: указанный выше SHA.
- Windows 11, build `10.0.26200`, AMD64; CPython **3.12.14**.
- Новая `.venv` создана установленным CPython 3.12, без копирования старой среды,
  локальных правок или результатов. Pip мог использовать кэш загруженных wheels.
- **Сначала только `requirements.txt`**: NumPy 2.5.3, pandas 3.0.6.
  Официальные команды, verify и run_demo завершены до установки dev-зависимостей.
  Затем установлен неизменённый `requirements-dev.txt`: pytest 9.1.1.
- Ключи и личные подписки не использовались. Обязательные пользовательские
  переменные окружения для проекта не понадобились. Обёртка записи логов задаёт
  `PYTHONUTF8=1` только для надёжного сохранения русского вывода команд.
- Физически это доступный локальный компьютер; **другой физический компьютер
  не проверен**. Новый clone и новое окружение не приравниваются к другому железу.
- Сравнение CSV выполнено с исходным файлом из проверенного main. Содержимое
  фактической загрузки на платформе не проверялось; финальная сдача не нажималась.

## Найденное замечание — не блокер запуска

**P3 — README.md:19, неоднозначная версия архивного benchmark.**

Воспроизведение: на проверенном SHA открыть README:19, затем ссылку
reports/benchmark-agent.md:3. README говорит «текущей версии», но целевой отчёт
фиксирует 409d9c0 и 2187b66, а не 571cb75. Более поздний
reports/benchmark_review_agent.json:5 также явно относится к 95e4555.

Ожидание: читатель видит конкретную версию каждого измерения. Фактически
«текущей» можно ошибочно отнести к HEAD. Минимальная правка основному
разработчику: заменить на «Подробные результаты для коммитов 409d9c0 и 2187b66 —
в reports/benchmark-agent.md. Это архивные измерения; воспроизводимость
проверяемой версии фиксируется отдельным отчётом приёмки».
README в этой ветке не изменялся. Новая официальная серия этой приёмки отдельно
подтвердила округлённые CLI-результаты на 571cb75.

## Что эта приёмка не подтверждает

Другой физический компьютер, Linux/macOS, прямой file:// и холодный запуск HTML
без сети, фактическую загрузку на платформе, реальные эффекты и скрытое
судейство. Новые product-коммиты после 571cb75 требуют новой проверки;
автоматически переносить на них этот вывод нельзя.

Все новые файлы находятся только в `reports/final_acceptance/`.
Алгоритм, tools, validation, зависимости и официальные исходники не менялись.
Полный набор исходных данных, `.venv`, ключи и личные пути не включены.

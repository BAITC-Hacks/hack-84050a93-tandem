## Замечание о версии local_eval и границы аудита

В `reports/push_integration/local_eval_ten_stdout.txt` **отсутствует SHA самого
запуска**. История Git подтверждает публикацию лога в коммите
`3af29c7aa40bf8c4467adb6654910b1c6077c7ae`; этот факт нельзя выдавать за записанный
SHA исполнения. Число 10/10 подтверждается содержимым лога. Это пробел
в фиксации происхождения результата, а не найденная числовая ошибка или блокер.

README корректно указывает, что доказательства относятся к разным исходным
версиям, а карта доказательств раскрывает эти версии и условия. Приёмка
интерфейса относится к Chrome через localhost; принудительное отключение сети,
другие ОС и второй физический компьютер для v1.3 не проверены. Прямое `file://`
также не проверялось. Синтетические результаты не являются измерением реального
эффекта Beeline или прогнозом скрытого судейства.

**Конкретные блокеры: отсутствуют.** Этот отчёт фиксирует уже выполненный аудит;
код, README, исходные свидетельства и результаты экспериментов не изменялись.

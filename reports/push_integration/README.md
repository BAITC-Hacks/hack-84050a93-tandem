# Приёмка дополнений v1.3

Проверка интегрированного `agent:Agent` после фиксированного исследования
[160 пар](../push_overlay/full_holdout.json). Проверки выполнены на Windows,
CPython 3.12.13, NumPy 2.5.3, pandas 3.0.6. Это существующее окружение
разработки с pytest; независимая новая чистая установка этой версии здесь
не заявляется.

## Результат

- [122 теста](tests_stdout.txt) прошли за 13,84 секунды. В том числе
  проверено совпадение AST базового алгоритма с `75716aa` и функций дополнения
  с замороженным `fbcd614`, а также точное совпадение production и
  исследовательского кандидата по кампаниям и пилотам на пяти сценариях.
  Для проверки исторических AST нужна история Git; в ZIP эти два теста
  явно пропускаются. Поведенческие проверки не требуют истории Git.
- [37 проверок воспроизводимости](verification.json) прошли: свежий процесс
  из другой рабочей папки воспроизводит CSV, исходники и данные совпадают
  с манифестом, исходный финальный префикс сохранён, подтверждены охват и лимиты.
- Два seed-42 экспорта совпадают: 5 кампаний (3 базовые + 2 бесплатные),
  20 пилотов, 6 732 контакта и 30 632 у.е. вместе с пилотами.
  Уникальная финальная аудитория — 2 476 клиентов.
- [Свежий полный запуск](demo_runs/run_20260923T114437Z_3enxsgf_/run_status.json)
  завершился за 4,89 секунды; все входы оставались неизменны.
- [Официальный local_eval, seed 0–9](local_eval_ten_stdout.txt):
  10/10 положительных результатов, медиана 1 476 624, минимум 1 058 935 у.е.
  Это синтетический mock; проверка положительного net не заменяет preflight.
- Renderer воспроизвёл полный CSV и JSON, проверил 14 исходников и 4 файла
  данных; отдельные тесты проверяют доказательства охвата и отказ от выдуманной
  суммарной прибыли. Синтаксис встроенного JavaScript проверен `node --check`.

Новый интерфейс v1.3 не проходил ручную проверку в браузере. Прежняя независимая
[браузерная приёмка](../final_acceptance/README.md) относится к версии `571cb75`.
Первый stdout local_eval испортился при передаче кодировки через PowerShell;
он сохранён как `local_eval_ten_encoding_failure.txt`, а повторный запуск
с явной UTF-8 записью сохранён в основном файле.

## Повторение

Из корня репозитория после установки зависимостей:

```powershell
.venv\Scripts\python.exe tools/verify_submission.py
.venv\Scripts\python.exe tools/run_demo.py
.venv\Scripts\python.exe -X utf8 local_eval.py --runs 10
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.venv\Scripts\python.exe -m pytest -q tests experiments/push_overlay
```

На Linux/macOS используется `.venv/bin/python`; такая платформа этой записью
не проверена. Исторические исходники и команды исследования описаны в
[техническом отчёте](../../docs/push_overlay.md).
